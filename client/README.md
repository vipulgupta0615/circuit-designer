# Circuit Studio web client

The Next.js client provides the landing page and the interactive 3D circuit editor.
For local setup, API configuration, simulator scope, and architecture, see the
[project README](../README.md).

Run the app from this directory with `npm install` followed by `npm run dev`.
To connect project save/load to the Express API, copy `.env.example` to
`.env.local` and set `NEXT_PUBLIC_API_URL`.
